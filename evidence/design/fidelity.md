# Design reference and implemented comparison

Reference created with the built-in imagegen tool, saved as studio-concept.png. Production evidence: ../production-studio.png and ../production-public-mobile.png.

| Reference decision | Implemented |
| --- | --- |
| Warm ivory workspace and forest green actions | Kept across studio and public chat |
| 210px navigation rail and two working columns | Kept on desktop; stacked responsive layout on mobile |
| Conversation as primary creation surface | Real model conversation with tool receipts and versioned artifact |
| Agent / Probar / Actividad panel tabs | All connected to actual persisted state |
| Prominent Publicar action and revision status | Publication bound to tested revision; live/paused state visible |
| Spanish hero and composer copy | Tu próximo compañero. and ¿Qué quieres que haga Quequito? retained |
| Dense small mockup labels | Increased minimum to11px and darkened after contrast audit |
| Decorative action controls in reference | Only functional controls; actual Clerk account menu and keyboard scroll targets |

The reference is a visual guide, not a bitmap used as UI. Actual instructions and history are longer than its sample content, so panels scroll. Markdown is rendered safely without raw HTML or remote images. Brand uses a typographic Q rather than the generated geometric logo. No marketing landing page was added.
